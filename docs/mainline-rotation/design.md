# 主线轮动比较设计

## 目标

复盘页的行业、概念主线均与当前复盘交易日之前最近一份复盘比较，明确展示新进前 10、跌出前 10及当日异常动量方向。

## 数据与时间口径

- 当前排名来自当前复盘的 `mainline.all_ranked` 或 `concept_mainline.all_ranked`。
- 基准排名来自 `/api/review/dates` 中严格小于当前复盘日的最近日期。
- 禁止用未来归档或仅用“不等于当前日”选择基准，确保历史回看不产生前视偏差。
- 行业和概念分别读取各自排名，不互相替代。

## 状态与降级

- 加载中：明确显示正在读取上一交易日排名。
- 无历史：显示“缺少上一交易日复盘，轮动比较待建立”。
- 历史读取失败：显示失败和基准日期，不伪造“无变化”。
- 当前或历史排名为空：显示排名数据不足。
- 比较成功：展示基准日期、新进、退出；没有变化时明确显示前 10 无变化。

## 验证

- 页面必须实际请求历史日期，并传入主线组件。
- 历史回看只能选择更早日期。
- 切换行业/概念后重新读取对应历史排名。
- 请求竞态不得让旧 tab 的返回值覆盖新 tab。
