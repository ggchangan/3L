# 复盘页 P0-1：市场环境与动态仓位重设计

## 背景

旧版复盘把大盘波段位置直接映射为固定仓位，例如“波中 → 七至八成”。这会造成两个问题：

1. 把波峰/波谷的交易节奏提示误解为必须达到的仓位目标；
2. 市场强弱、主跌风险和波段位置混在一个结论里，可能出现“下降趋势 + 波中 + 建议七至八成”的冲突。

## 3L 规则依据

本次设计以知识库中的《大盘定性》、训练营《仓位控制》《强弱结构判断及买卖点匹配》为准：

- 大盘用于识别市场环境和回避主跌段；
- 强弱市场主要影响可用买点、出手频率、持股周期和止盈节奏；
- 波峰控仓、波谷重仓，但波谷不能代替主线方向和个股有效买点；
- 实际仓位由持仓卖出和有效买入逐笔形成，不以一个静态百分比为目标；
- 只要不处于主跌段，继续关注方向与个股买卖点。

## 分层模型

大盘策略拆成三个互不替代的判断：

1. **市场环境**：强势 / 震荡 / 弱势。决定买点偏好、交易频率、持股和止盈节奏。
2. **风险阶段**：主跌风险 / 风险升高 / 波谷修复 / 常态。决定是否允许新增仓位以及是否优先退出风险持仓。
3. **波段位置**：偏波峰 / 波中 / 偏波谷。作为仓位变化的节奏信号，不再输出固定总仓位。

### 风险阶段规则

- 下降趋势且未形成明确波谷：主跌风险，暂停新增仓位，先执行卖出计划；
- 明确偏波峰或严重正乖离：风险升高，不追高，优先兑现和收紧止盈；
- 明确偏波谷：波谷修复，可以根据主线/强动量中的有效个股买点逐步增加仓位；
- 其他情况：常态，按方向和个股信号动态调整。

弱势市场本身不等于固定低仓位；它改变交易方式。弱势环境优先恐慌、供应衰竭和反转类买点，缩短持股周期并收紧止盈。只有主跌风险才形成硬门禁。

## 动态仓位契约

`trading_plan.market_strategy` 返回：

- `environment` / `environment_label`：市场环境；
- `risk_phase` / `risk_label`：风险阶段；
- `wave_phase` / `wave_label`：波段位置；
- `position_mode` / `position_action`：当前仓位动作；
- `current_position_pct`：持仓记录中仓位比例的合计；
- `planned_exit_pct`：已生成明确卖出计划的持仓比例；
- `position_after_exits_pct`：执行明确卖出后的仓位，不包含尚未触发的条件买入；
- `executable_buy_count`：当前可执行重点买点数；
- `allowed_buy_points` / `avoid_buy_points`：当前环境的买点偏好；
- `holding_style` / `exit_style`：持股与退出节奏；
- `summary` / `basis`：可直接展示的结论和依据。

仓位比例缺失时返回 `null`，不猜测；减仓但比例不明确时只提示动作，不虚构减仓后的数字。

## 页面设计

复盘第一屏按照下面顺序展示：

1. 明确显示“强势 / 震荡 / 弱势市场”；
2. 独立显示风险阶段和波段位置；
3. 用“当前仓位 → 明确卖出后仓位”代替“建议总仓位”；
4. 展示当前允许的买点、避免的买点、持股节奏和止盈节奏；
5. 每日计划继续展示逐只买卖动作，实际仓位随这些动作自然变化。

## 兼容与验收

- 旧字段 `position_pct` 保留在 API 中供历史缓存兼容，但页面不再把它显示为建议仓位；
- 旧版 `market_filter` 的 `filter` 字段继续保留，移除静态最大仓位语义；
- 下降趋势 + 波中必须显示主跌风险，不得再显示“建议七至八成”；
- 弱势 + 明确波谷必须显示波谷修复，不得因 `vl_score≥4` 被判定为休息；
- 生产持仓比例可以计算时，页面必须展示真实当前仓位以及明确卖出后的仓位；
- 所有结论必须能从市场环境、结构、波段位置和实际交易动作中解释。
